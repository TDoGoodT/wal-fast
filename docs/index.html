Quick Start

Up and running in minutes.

# Install dependencies opam install dune ocaml-lsp-server alcotest cmdliner # Clone and build git clone https://github.com/TDoGoodT/wal-fast cd wal-fast dune build # Inspect a trace dune exec bin/main.exe -- index simulation.vcd # Run a WAL script dune exec bin/main.exe -- run analysis.wal simulation.vcd # Interactive REPL dune exec bin/main.exe -- repl simulation.vcd
Language

WAL Lisp — quick reference.

; Arithmetic (+ 1 2) ; => 3 (define square (lambda (n) (* n n))) (square 5) ; => 25 ; Signal access — VCD signals are in scope clk ; => current value of signal "clk" data ; => current value of signal "data" ; Iterate over all timesteps (for-each-timestep (if (= clk 1) (println data))) ; Find first rising edge (find-first (lambda () (rising-edge clk)))
